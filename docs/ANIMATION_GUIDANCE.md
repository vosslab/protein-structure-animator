# Agent animation guidance

Discover demonstrated capabilities in [TOOLS.md](TOOLS.md) and adapt the closest example. Read
the human's request and [HUMAN_GUIDANCE.md](HUMAN_GUIDANCE.md). Existing examples are references;
the agent chooses tools for the requested representation, science and delivery.

1. Identify the protein, experimental states or trajectory, biological assembly, intended teaching
   point and requested media. Verify primary structural records rather than trusting a familiar PDB
   identifier or an external LLM's recommendation.
2. Preserve original inputs and hashes. Inspect sequences, chain identity, missing residues and
   atoms, alternate conformers, occupancies, ligands and mutations. Record every selected omission.
   Keep an entire requested assembly; change renderer when legacy formats cannot preserve it.
3. Choose a scientific motion class: changing viewpoint, experimental endpoint interpolation,
   simulation, predicted mode or authored staging. State the classification beside the delivery.
   Interpolation and selected playback speed establish neither a pathway nor kinetics.
4. Prefer native algorithms and commands. Check actual coordinate handoffs for atom identities,
   coordinates, frame count and ligand registration. Compare the imported result, not merely the
   exporter return code. Treat unmatched ligands separately from protein morphing.
5. Select illustrated spheres or a smooth molecular surface deliberately. Preserve a useful camera,
   projection, scale, color palette and background. Inspect ligand visibility throughout motion;
   disclose transparency or cutaways. Compare real images at teaching size.
6. Render in a fresh process, inspect intermediate frames and playback, encode requested media,
   and test the seam. Check browser and Impress slideshow behavior separately.
7. Replay from the documented inputs and commands. Deliver media, a poster, native scripts/settings,
   structural references, a short method note and the actual verification record.

Keep observations separate: correct scientific preparation, file fidelity, visual acceptance,
decodability, application playback and reproduction are different evidence. Repair a failed check,
repeat the affected check and update the example record. Do not silently call a partial milestone
complete. Leave the active plan in place while any required check remains outstanding.

Run graphics experiments sequentially on this Mac. Keep Blender optional and do not launch it for
these initial examples. Use the repository Python bootstrap for repo scripts and each external
application's own runtime for native scripts. Add helpers only for gaps exposed by the examples;
a viewer, orchestration framework, adapters, MCP server and custom recipe schema remain deferred.
